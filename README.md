# 📋 Registro de Hermanos

Panel web para consultar el registro de hermanos y sus asignaciones del programa.

## 👀 Qué puedes ver

- 📊 **Resumen**: total de hermanos, activos, inactivos y en salud.
- 👥 **Por grupo**: barras de los grupos 1 al 5, con activos e inactivos diferenciados por color.
- 🏷️ **Por tarea**: una tarjeta por cada tarea con el total y la división entre mujeres y varones.
- ✅ **Disponibilidad por asignación**: cuántos hermanos activos pueden tomar cada asignación.
- 🙋 **¿Quién puede tomar una asignación?**: elige una asignación y aparece la lista de hermanos disponibles.
- 🔍 **Listado**: tabla completa con buscador por nombre y filtros por grupo, tarea, género, estado y asignación.
- 🌗 **Tema automático**: se adapta al modo claro u oscuro del dispositivo.

## 📱 Uso

Abre la página desde cualquier dispositivo. Está adaptada para celular, tablet y computador.
